# 🐾 Animal Games

A collection of small browser games, one for each animal.
Every animal has its own coins, skins, accessories, skills and achievements.

## Games
- 🐍 Snake (1 and 2 players)
- 🐰 Rabbit
- 🐒 Monkey
- 🐨 Koala
- 🐟 Fish
- 🐸 Frog and 🐭 Mouse (coming soon)

## How to play
Open the site, pick an animal and play. No installation needed.
