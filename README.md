# Snake Game 🐍

A browser snake game with fruits, levels, coins and unlockable skins.

**[▶ Play it here](https://ecemkaradas.github.io/snake_game/)**

## Features

- Smooth snake movement with an animated tongue and eyes
- Three fruits: blackberry, strawberry and orange (special fruits appear every few berries)
- Levels that make the snake faster, with a new rank at each level
- Earn coins from your score and spend them on new snake skins
- Every skin evolves through its own color palette and turns rainbow at the final level
- Main menu with a live snake preview and a skin shop

## Controls

| Key | Action |
| --- | --- |
| Arrow keys | Move the snake / start the game |
| Space | Play again after Game Over |
| M or Esc | Back to the menu |
| Enter | Start the game (from the menu) |

## Built with

Plain HTML, CSS and JavaScript (canvas). No libraries.

## Run it locally

Download `index.html` and open it in your browser.
